Use a Pakon without Windows XP or a virtual machine

OpenPakon is free software that runs the scanner on the computer you already have: a Mac, Windows 10 or 11, or Linux.

{{downloads}}

The old way

The Pakon's software only runs on Windows XP. So for years, owners have had two choices: keep an old XP laptop alive just for the scanner, or set up a Windows XP "virtual machine" (a pretend old PC running inside a new one). Both work, but both are slow, fragile and hard to set up, and finding a working copy of XP gets harder every year.

The new way

Install OpenPakon like any other app, plug in the scanner, and scan. That's it.
