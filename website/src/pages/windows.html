Use your Pakon on Windows 11, no XP

A free app for the Kodak Pakon F-135 and F-135+ on a modern Windows PC. The scanner driver comes with it.

{{download:windows}}

Why the old software stopped working

The Pakon's own software (TLX and PSI) and its driver were made for Windows XP. Newer versions of Windows won't run that driver, so people kept old XP laptops around just for the scanner. OpenPakon comes with a driver that works on Windows 10 and 11.

Install

  1. Download Pakon-Setup.exe above and open it.
  2. If Windows warns you ("Windows protected your PC"), click More info, then Run anyway. The app isn't signed yet, which is why Windows doesn't recognise it.
  3. Say yes when Windows asks for administrator permission. That's the installer setting up the scanner's driver. It only happens once.
  4. Plug in the scanner with its USB cable, switch it on and open the app.

Then follow the guide to your first scan.

OpenPakon's installer replaces Kodak's scanner driver if you had it installed.

Updating

OpenPakon tells you when there's a new version. Quit OpenPakon and run the new installer. Your scans and settings stay where they are.
